# Ballistic Simulation Engine

Python tools for simulating macroscopic ballistic penetration and training a physics-informed neural network (PINN) surrogate.

## Features

- Johnson–Cook, Cowper–Symonds, and Recht–Ipson material and failure models
- Trajectory simulation and PINN training data generation
- FCNN and PINN training, inference, and optional interactive demos
- Unit tests and golden simulation cases

## Requirements

Python 3.10 or newer. Install the project and its dependencies with:

```bash
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
# macOS/Linux: source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e .
```

For tests and development tools, install the optional development dependencies with `python -m pip install -e ".[dev]"`.

## Run a simulation

From the repository root:

```bash
python -c "from ballistic.simulation import simulate_trajectory; r = simulate_trajectory(plate_thickness_mm=10.0, material_name='RHA_steel', bullet_velocity_ms=850.0, bullet_mass_g=7.9, bullet_diameter_mm=7.62); print(r['V_ms'][-1])"
```

## Train and run inference

Generate PINN training data, then train the PINN:

```bash
python scripts/data/generate_data.py
python scripts/train/train_pinn.py
```

Run the inference command or see its options:

```bash
python scripts/viz/infer.py --help
```

Training checkpoints and generated figures, reports, and logs are written locally under `models/` and `results/`. They are not required in a source checkout; data can be regenerated with `scripts/data/generate_data.py`.

## Optional demos

Install the optional demo dependencies with `python -m pip install -e ".[demos]"`, then run:

```bash
streamlit run app/streamlit_app.py
# or
python app/gradio_demo.py
```

## Tests

```bash
python -m pytest
```

## Project layout

```text
app/                Interactive demos (Streamlit, Gradio)
ballistic/          Core simulation and PINN package
  models/           Neural network architectures
  physics/          Material models and physics residuals
  dataloader.py     PINN dataset handling
  simulation.py     ODE trajectory simulation
docs/               Model assumptions and project report
models/             Model checkpoints (gitignored; regenerated by training scripts)
notebooks/          Exploratory analysis notebooks
pinn_data/          Generated training data (gitignored)
results/            Generated figures and reports (gitignored)
scripts/            CLI entry points and utilities
  data/             Data generation and audit
  train/            Training scripts
  eval/             Benchmarks and validation
  viz/              Figure generation and inference
tests/              Unit tests and golden simulation data
validation/         Format and location for experimental CSV data
```
