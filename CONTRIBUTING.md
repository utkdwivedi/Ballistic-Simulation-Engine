# Contributing Guidelines

We welcome contributions! Please follow the steps below:

1. **Fork and branch** – Create a branch from `main` named `feature/your-name`.
2. **Tests first** – Add or update unit tests. All tests must pass locally before you push.
3. **Lint & type check** – Run `ruff check . && mypy .` to ensure code style and typing.
4. **Commit** – Remember the attribution footer:
   ```md
   Co‑Authored‑By: Claude Code <noreply@anthropic.com>
   ```
5. **Pull request** – Submit a PR against `main`. In the PR description append:
   ```md
   🤖 Generated with [Claude Code](https://claude.com/claude-code)
   ```

Thanks for helping keep the project healthy!
